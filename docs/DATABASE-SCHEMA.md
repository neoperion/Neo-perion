# Database Schema Overview

## 1. CMS Domain
- `blogs`: Stores markdown blog content, author details, and SEO metadata.
- `case_studies`: Stores client success stories, challenges, and impact metrics.
- `testimonials`: Client quotes, ratings, and company info.
- `careers`: Job openings, requirements, and locations.

## 2. CRM & Lead Management
- `leads`: Contact forms and inbound inquiries.
- `newsletter_subscribers`: Email subscriptions.
- `job_applications`: Incoming resumes and applicant details.

## 3. Compliance System
- `cookie_consents`: Tracks IP hashes, session IDs, and consent versions for compliance audits.

## Storage Buckets (Supabase)
- `blog-images`
- `case-study-images`
- `founders`
- `documents`
- `resumes`
- `company-assets`
