# Neo Perion V2.0 - Asset Plan

## 1. Hero Assets
- **Neural Network Visual**: A dynamic, interactive 3D WebGL/Three.js canvas serving as the primary background for the hero section.
- **AI Graphics**: Abstract glowing particle systems or abstract data flow visualizations.

## 2. Technology Logos
- `react.svg`: React logo (cyan)
- `supabase.svg`: Supabase logo (green)
- `gemini.svg`: Google Gemini logo (multi-color)
- `aws.svg`: Amazon Web Services logo
- `azure.svg`: Microsoft Azure logo
- `gcp.svg`: Google Cloud Platform logo

*Note: All tech logos must be transparent SVG format with uniform padding.*

## 3. Industry Graphics
- **Education**: `industry-education.webp` (AI tutor representation)
- **Startup**: `industry-startup.webp` (Rocket or growth graph representation)
- **SMB**: `industry-smb.webp` (Dashboard and automation representation)
- **Healthcare**: `industry-healthcare.webp` (Medical data flow representation)

*Note: All images must be optimized WebP format with a maximum file size of 200KB.*
